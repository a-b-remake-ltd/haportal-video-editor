# HAPORTAL - VIDEO EDITOR

**English:** [README.en.md](README.en.md)

סקיל לקלוד קוד שהופך צילום גולמי של דיבור למצלמה לרילס גמור ומקצועי, מוכן להעלאה לאינסטגרם, טיקטוק ויוטיוב שורטס.

נותנים לו את הצילום, והוא חותך, מעצב, מוסיף כתוביות, מוזיקה, אפקטים וגרפיקה, ומוציא קובץ סופי באיכות גבוהה, עם כללי עבודה של עורך מקצועי. הוא בנוי קודם כול לעברית, ומזהה לבד גם סרטון בשפה אחרת.

---

## מה הוא יודע לעשות

**חיתוך מדויק לדיבור.** בלי שקטים מתים, בלי נשימות אחרי קאט, בלי מילים חתוכות בסוף משפט. כשיש כמה טייקים של אותו משפט, הוא בוחר את הטוב.

**מתאים את עצמו לרפרנס שלך.** נותנים לו סרטון שאוהבים את הסגנון שלו, או סרטונים קודמים שלכם, והוא מודד את הקצב, את סגנון ומיקום הכתוביות ואת עוצמת המוזיקה, ומתאים את העריכה. הוא מעתיק את שפת העריכה, לא את התוכן.

**גריד של אינסטגרם.** שום טקסט או לוגו לא נופל מתחת לכפתורים, לשם המשתמש או לכותרת של האפליקציה. יש בדיקה אוטומטית שעוצרת את התהליך אם משהו חורג.

**רק פונטים חינמיים.** כל פונט שנכנס לסרטון מורשה לשימוש מסחרי. הסקיל מסרב לפונטים בתשלום, כדי שלא תסתבכו בזכויות.

**צבעי המותג מהלוגו.** נותנים לו לוגו, והוא מחלץ ממנו את צבעי המותג ומתאים אליהם את הגרפיקה, ההנפשות וההדגשות בטקסט. הוא גם בודק שהטקסט קריא על כל רקע.

**סגיר מונפש עם הלוגו.** אם יש לוגו ורוצים, הסרטון נסגר בהנפשה: הפריים נסגר לדלת שעפה לתוך הסמל של הלוגו, והלוגו נבנה סביבו, ממורכז. יש עוד שלושה סגנונות לבחירה.

**כותרות קינטיות.** המשפט החשוב נבנה על המסך מילה אחרי מילה, בדיוק כשהיא נאמרת, עם מילת המפתח בצבע המותג.

**רגעים מעוצבים.** עולם נייר עם מעבר דף, כרטיס שאלה, רשימת וי, חותמת, תגיות קופצות, שורת חיפוש שמוקלדת ומעוף של הפריים לעולם צבעוני. כל רגע נבחר לפי מה שנאמר באותה שנייה.

**מוזיקה שנוצרת לכל סרטון.** אם יש לכם מפתח של אילבן לאבס, הסקיל מייצר מוזיקה מקורית שבנויה לפי הסיפור, עם שינוי שנוחת בדיוק ברגע המפנה. בלי מפתח אפשר לתת לו קובץ מוזיקה משלכם.

**עברית קודם כול, וכל שפה אחרת.** תמלול עברי חינמי ומדויק, כתוביות שנשברות במקום הנכון, ו״AI״ שלא נראה כמו ״Al״. סרטון בשפה אחרת מזוהה לבד, והכתוביות והגרפיקה מתהפכות לכיוון הנכון.

## מה צריך

1. מחשב מק (עדיף עם שבב אפל) או מחשב לינוקס.
2. קלוד קוד מותקן.
3. דפדפן כרום.
4. כמה גיגה פנויים בדיסק, בשביל מודל התמלול.

את כל השאר הסקיל בודק ומתקין לבד.

## התקנה

פותחים את הטרמינל ומריצים את שלוש השורות האלה, אחת אחרי השנייה.

מורידים את הסקיל לתיקיית הסקילים של קלוד:

```
git clone https://github.com/a-b-remake-ltd/haportal-video-editor ~/.claude/skills/haportal-video-editor
```

נכנסים לתיקייה:

```
cd ~/.claude/skills/haportal-video-editor
```

מריצים את ההתקנה האוטומטית:

```
python3 scripts/doctor.py --install
```

ההתקנה בודקת מה חסר, מתקינה מה שאפשר ומסבירה בדיוק מה לעשות עם מה שלא. בסוף צריכה להופיע רשימה ירוקה.

אפשר גם פשוט לבקש מקלוד: ״תתקין לי את הסקיל של הפורטל לעריכת וידאו״, ולתת לו את הקישור.

## איך משתמשים

1. יוצרים תיקייה חדשה לסרטון ומכניסים אליה את הצילום הגולמי. אם יש, מוסיפים גם בירולים, לוגו וסרטון רפרנס.
2. פותחים את התיקייה בקלוד קוד.
3. כותבים: ״ערוך לי את הסרטון לרילס״.

קלוד יעבור על החומר ויחזור עם כמה שאלות קצרות:

* יש סרטון רפרנס שאתה אוהב את הסגנון שלו?
* יש לוגו? נתאים את הצבעים למותג.
* רוצה סגיר מונפש עם הלוגו בסוף?
* הסרטון אורגני, או שירוץ גם כמודעה ממומנת?

אחר כך הוא יציג תוכנית עבודה בכמה משפטים, ורק אחרי האישור שלכם יתחיל לערוך. לפני שהוא מראה לכם משהו, הוא בודק את התוצאה בעצמו: כל נקודת חיתוך, הגריד, הכתוביות ועוצמת הסאונד.

הערות שולחים בשפה חופשית, למשל ״הכתוביות גדולות מדי״ או ״בשנייה 12 חתכת מוקדם״. הוא מתקן את הבעיה וגם מחפש את אותה טעות בשאר הסרטון.

## טיפים לתוצאה הכי טובה

* **צלמו בתאורה טובה ובשקט.** הסקיל לא מציל אודיו גרוע.
* **אם טעיתם, פשוט תגידו את המשפט שוב.** הוא יודע לבחור את הטייק האחרון.
* **רפרנס עוזר מאוד.** סרטון אחד שאתם אוהבים שווה יותר מכל הסבר.
* **לוגו כקובץ פי אן ג׳י עם רקע שקוף** נותן את הצבעים והסגיר הכי מדויקים.
* **מוזיקה:** עם מפתח של אילבן לאבס היא נוצרת לבד. בלי מפתח, תנו לו קובץ מוזיקה שיש לכם רישיון אליו.
